# 체스 마스터 (Chess Master) - 온라인 WiFi & AI 훈련

U24(장기) 프로젝트와 마찬가지로 로컬/와이파이 환경에서 편리하게 즐길 수 있는 **실시간 체스 게임**입니다.

## 주요 기능

1. **와이파이(LAN) 2인 온라인 대국**:
   - 같은 공유기(WiFi)나 로컬 네트워크에 연결된 스마트폰, 태블릿, PC 등에서 브라우저로 실시간 2인 대국을 진행할 수 있습니다.
   - 방 개설 시 생성되는 **QR 코드**를 스마트폰 카메라로 스캔하거나 **4자리 방 코드**를 입력하여 1초 만에 참여할 수 있습니다.
   - 실시간 시계 타이머, 무승부 제안, 기권, 재대국, 실시간 빠른 이모티콘 및 채팅 지원.

2. **혼자 AI와 훈련 (AI Training)**:
   - **5단계 난이도** (1단계: 초심자 ~ 5단계: 마스터)를 제공하는 미니맥스/알파-베타 체스 AI 엔진 내장.
   - **실시간 형세 분석 바 (Evaluation Bar)**: 폰 점수 단위로 실시간 유리/불리 형세 그래프 제공.
   - **최선수 힌트 (AI Hint)**: 위기 상황이나 연습 시 가장 좋은 추천 수를 시각적으로 안내.
   - **수 물리기 (Undo)** 기능 제공.

3. **1개 기기 로컬 2인 대국 (Pass & Play)**:
   - 한 모니터나 태블릿에서 둘이서 마주보고 번갈아 둘 수 있는 모드.
   - 수를 둘 때마다 체스판을 자동으로 180도 회전시켜주는 기능 지원.

4. **프리미엄 UI / 사운드 시스템**:
   - 깔끔한 Staunton 벡터(SVG) 기물과 4종 체스판 테마 (다크 슬레이트, 클래식 우드, 에메랄드 그린, 미드나잇 골드).
   - Web Audio API 기반 지연 없는 체스 효과음 (착수, 캡처, 체크, 캐슬링, 승리 팡파레).
   - 국제 표준 FEN 및 PGN 기보 복사 지원.

## 실행 방법

```bash
cd /home/kw/chess
npm start
```
또는
```bash
./launch-app.sh
```

- **PC 브라우저 접속**: `http://127.0.0.1:8080` 또는 `http://localhost:8080`
- **동일 WiFi 스마트폰 접속**: 상단에 표시되는 WiFi IP(예: `http://172.30.1.70:8080`) 또는 화면의 **QR 코드**를 카메라로 스캔하여 접속.
- 포트 변경이 필요할 경우: `PORT=9100 npm start`
